介绍

当您想把文本内容只让少数人阅读时，可以使用摩斯密码转换器保存编码，之后再将其还原为可阅读的文本。您也可以把摩斯密码用语音播放出来，用它学习和练习电报码。

使用方法

在左侧输入文本，工具会自动生成摩斯密码；也可以直接在右侧输入编码并还原文本。编码由“.”、“-”和空格组成，字符之间用空格隔开，单词之间用“ / ”隔开。

播放按钮可以试听当前编码，并可手动调节播放进度。短促的点信号“·”读作“di”，长信号“—”读作“da”；本工具采用 1t = 0.08 秒。
