《中文文案排版指北》核心规范速查
1. 中英文之间添加空格（盘古之白）
在中文与英文字符、拉丁字母之间应保留一个半角空格，增强视觉通透感与阅读呼吸感。
✕ 在精通Vue和React之后
✓ 在精通 Vue 和 React 之后
2. 中文与数字之间添加空格
在中文与阿拉伯数字之间应保留一个半角空格；年/月/日/度/楼层等特定紧凑量词除外。
✕ 共进行了3次测试，耗时5分钟
✓ 共进行了 3 次测试，耗时 5 分钟
3. 数字与常用物理/存储单位之间空格
数字与 MB、GB、GHz、ms、kg 等常用计量单位之间应保留一个半角空格（百分比与度数除外）。
✕ 硬盘剩余100GB，CPU主频3.2GHz
✓ 硬盘剩余 100 GB，CPU 主频 3.2 GHz
4. 中文语境下使用全角标点
中文句子内部或句末必须使用全角标点符号（如逗号、句号、感叹号、问号、冒号、中文括号）。
✕ 你好,请问你的名字是?
✓ 你好，请问你的名字是？
5. 全角标点与其他字符间不留空格
中文全角标点在字模中已自带天然空白间距，因此前后严禁再人为插入冗余空格。
✕ 你好 ， 欢迎使用 在线工具集 。
✓ 你好，欢迎使用 在线工具集。
6. 规范使用成对引号格式
统一使用现代规范弯双引号 “ ” 与 ‘ ’，或出版直角引号 「 」 与 『 』，杜绝 ASCII 英文直引号。
✕ 他说:"这是一个'绝妙'的主意"
✓ 他说：“这是一个‘绝妙’的主意”
