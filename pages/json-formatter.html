JSON 格式与开发规范说明

JavaScript Object Notation (JSON) 是一种轻量级的数据交换格式，基于 ECMAScript 标准衍生，广泛应用于 Web API、微服务通信、配置文件及持久化存储中。

标准 JSON 格式约束

  • 键名 (Key) 必须用双引号 "..." 包裹，不允许单引号或无引号。
  • 字符串值必须使用双引号包裹，不可使用反引号或未转义换行。
  • 对象与数组最后一个元素后面禁止包含尾随逗号 (Trailing comma)。
  • 支持的值类型：字符串 (String)、数值 (Number)、布尔值 (true/false)、空值 (null)、对象 (Object)、数组 (Array)。

本工具箱特色优势

  • 行号精确报错与自愈：精准定位语法错误行与列，并能智能自动修复单引号、尾随逗号及未加引号键名。
  • 类型代码自动生成：从复杂 JSON 一键推断生成严谨的 TypeScript 接口与 Go 结构体代码。
  • 全树交互与路径速查：一键折叠/展开任意深度树节点，悬停即可一键提取 JSONPath 路径。
