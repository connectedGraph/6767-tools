数学表达式支持与全功能指南

1. 显函数 (Explicit y=f(x))

  • 代数多项式: x^2 - 2x + 1, x^3 - 3x
  • 指数与对数: exp(-x/2), log(x), ln(x)
  • 三角与双曲: sin(x), tan(x), tanh(x)
  • Sinc采样函数: sinc(x) 或 sin(x)/x

2. 隐函数与圆锥曲线

  • 圆形与椭圆: x^2 + y^2 = 25, x^2/16 + y^2/9 = 1
  • 双曲线与抛物线: x^2 - y^2 = 1, y^2 = 4x
  • 代数心形方程: (x^2+y^2-4)^3 - x^2*y^3 = 0
  • 椭圆曲线密码学: y^2 = x^3 - 3x + 3

3. 极坐标与参数方程

  • 经典心形线: r = 2 * (1 - cos(theta))
  • 四叶/三叶玫瑰线: r = 3 * sin(2*theta)
  • 阿基米德螺线: r = 0.5 * theta
  • 星形线 / 摆线: x=4*cos(t)^3, y=4*sin(t)^3

4. 微积分与交互功能

  • 导数切线追踪: 鼠标悬浮自动显示实时切线与斜率
  • 精确符号导数: 集成 math.js 自动生成解析导数公式
  • 闭区间定积分: 梯形/辛普森复合数值积分与面积阴影
  • 图像导出: 离线生成 2x 高清 PNG 与纯矢量 SVG

介绍

本 2D 函数图像绘制器深度集成 math.js 与 function-plot 纯前端渲染引擎，支持单屏多函数方程绘制、微积分导数切线实时计算、定积分面积着色及高清图片导出，适配各类屏幕及副屏展示。
