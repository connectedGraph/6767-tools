介绍

SQL 格式化工具基于业界主流的 sql-formatter 解析引擎构建，支持 Standard SQL、MySQL、PostgreSQL、Oracle PL/SQL、SQLite、SQL Server (T-SQL) 等多种 SQL 方言。提供关键字大写转换、自定义缩进、单行压缩与一键导出功能，帮助开发者快速规范数据库脚本与日志查询语句。
