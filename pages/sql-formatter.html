工具介绍与功能特性

SQL 格式化与美化器基于业界领先的 sql-formatter 语法解析引擎构建，支持 Standard SQL、MySQL、MariaDB、PostgreSQL、Oracle PL/SQL、SQLite、SQL Server (T-SQL) 等主流数据库方言。支持一键转换关键字大写、2/4 空格及 Tab 缩进、去除冗余注释与压缩单行 SQL，满足开发者在编写查询、审查日志、重构存储过程等多场景下的代码美化需求。

🌐 多方言语法兼容
深度适配 MySQL、PostgreSQL、Oracle、SQLite、T-SQL 特有语法结构与操作符。
📐 自定义层级缩进
支持灵活切换 2 空格、4 空格或 Tab 制表符缩进，符合不同工程规范标准。
🔠 关键字规范大写
智能统一 SELECT、JOIN、GROUP BY、OVER 等关键字大写，显著提高 SQL 可读性。
🔒 纯本地离线解析
所有 SQL 文本均在客户端浏览器完成排版转换，绝不上云存储，确保数据安全。
