📖 CSS 渐变函数语法详解

linear-gradient()

沿一条直线方向混合两种或多种颜色。接受角度（如 135deg、to bottom right）以及任意数量的色标位置。

radial-gradient()

从单一原点向外辐射扩散过渡，支持圆形 (circle) 或椭圆 (ellipse)，以及到最近/最远角侧的边界范围。

conic-gradient()

围绕中心点顺时针旋转过渡（形如饼图或色轮），非常适合制作现代雷达扫描、彩虹色轮或发光环形效果。
