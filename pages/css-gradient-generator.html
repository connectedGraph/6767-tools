📖 CSS 渐变函数语法详解

linear-gradient()

沿直线方向混合两种或多种颜色，接受角度与任意数量的色标位置。

radial-gradient()

从单一原点向外辐射扩散，支持圆形、椭圆及多种边界范围。

conic-gradient()

围绕中心顺时针旋转过渡，适合色轮、雷达扫描与发光环效果。
