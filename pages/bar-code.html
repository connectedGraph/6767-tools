Code 39与code 128条形码的区别

CODE 39码的编码规则是：1、每五条线表示一个字符；2、粗线表示１，细线表示０；3、线条间的间隙宽的表示１，窄的表示０；4、五条线加上它们之间的四条间隙就是九位二进制编码，而且这九位中必定有三位是1，所以称为39码；5、条形码的首尾各一个＊标识开始和结束。

CODE 128是一种高效率条码，共映射106种编码，广泛应用在企业内部管理、生产流程和物流控制系统方面，是应用最广泛的条码码制之一。

CODE128码与CODE39码都广泛运用于企业内部管理、生产流程、物流控制系统。不同在于Code 128能表现更多字符，单位长度里的编码密度更高，因此更具灵活性。

条形码的介绍

条码是将线条与空白按照一定的编码规则组合起来的符号，用以代表一定的字母、数字等资料。条码阅读机扫描后，经光电转换、解码即可还原为相应的文数字，再传入电脑。条码辨识技术成熟可靠，具有输入快速、准确性高、成本低、应用面广等特点。

世界上有225种以上的一维条码，每种一维条码都有自己的编码规格。一般较流行的一维条码有39码、EAN码、UPC码、128码，以及用于书刊管理的ISBN、ISSN等。
