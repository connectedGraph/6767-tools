时间戳转换

在日期、Unix 时间戳与常见标准格式之间快速转换，结果可一键复制。
实时转换工作台
支持 Timestamp / Unix / ISO / RFC / UTC

关于时间戳

时间戳是从格林威治时间 1970 年 01 月 01 日 00:00:00 起至现在的总秒数。本工具同时提供本地时间、UTC、JavaScript、ISO 8601、RFC 2822 以及毫秒和十六进制结果。

常用代码

Swift

NSDate().timeIntervalSince1970

Go

import ( "time" )
int64(time.Now().Unix())

JavaScript

Math.round(new Date() / 1000)

Python

import time
time.time()

Shell

date +%s
