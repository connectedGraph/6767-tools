🔍 什么是 Backdrop-filter？
CSS `backdrop-filter` 能够直接对元素背后的图层应用高斯模糊与饱和度调整，无需像传统方案那样克隆背景图，渲染性能极高且支持动态内容。
🍎 Safari 浏览器兼容性前缀
在 WebKit 内核 (Safari / iOS 浏览器) 中，必须声明 `-webkit-backdrop-filter: blur(...)` 才能生效，本工具生成的 CSS 已自动内置该前缀。
✨ 打造通透毛玻璃三要素
1. 足够的背景模糊 (12~24px)；2. 低透明度背景 (rgba 0.1~0.3)；3. 细高光半透明边框 (1px border-white/20) 强化立体边缘感。
