元字符 / 语法 说明 示例
.匹配除换行符以外的任意单个字符 (s 修饰符下匹配包含换行符)a.c → "abc", "a c"
\d / \D匹配数字 [0-9] / 匹配非数字 [^0-9]\d{3} → "123"
\w / \W匹配字母、数字、下划线 [A-Za-z0-9_] / 非单词字符\w+ → "user_01"
\s / \S匹配任何空白字符 (空格、制表、换页等) / 非空白字符\s+ → " "
^ / $匹配字符串或行首 (m模式下) / 匹配字符串或行尾^\d+$ → 纯数字行
\b / \B匹配单词边界 / 非单词边界\bcat\b → "cat"
* / + / ?匹配 0 次或多次 / 匹配 1 次或多次 / 匹配 0 次或 1 次a*b, a+b, a?b
{n,m}匹配最少 n 次，最多 m 次\d{6,18}
(...)捕获组，提取匹配子串并记录 Group 索引(\d{4})-(\d{2})
(?:...)非捕获组，仅用于分组而不捕获文本(?:https?|ftp)
(?<name>...)命名捕获组，可通过名称提取 Group(?<year>\d{4})
(?=...)正向先行断言 (Lookahead)：后面必须跟随匹配内容\d+(?=px)
(?!...)负向先行断言：后面不能跟随匹配内容\d+(?!px)
(?<=...)正向后行断言 (Lookbehind)：前面必须是匹配内容(?<=\$)\d+
(?<!...)负向后行断言：前面不能是匹配内容(?<!\\)\$
