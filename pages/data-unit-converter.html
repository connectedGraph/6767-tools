💽 硬盘/U盘标称容量 与 Windows 系统实际显示折算 (1000进制 vs 1024进制)

📚 进阶度量衡核心换算公式说明

• 数据存储单位：SI 十进制标准 (KB = 1000 B, MB = 10⁶ B, GB = 10⁹ B, TB = 10¹² B)；IEC 二进制标准 (KiB = 1024 B, MiB = 1048576 B, GiB = 1073741824 B, TiB = 1099511627776 B)。

• 工程压强：1 标准大气压 (atm) = 101,325 Pa = 1.01325 bar = 760 mmHg (Torr) = 14.696 psi = 1.0332 kgf/cm²。

• 机械功率：1 公制马力 (ps) = 735.49875 W；1 英制马力 (hp) = 745.69987 W；1 kW = 1.3596 ps = 1.341 hp。

• 物理航速：1 节 (knot) = 1 海里/小时 = 1.852 km/h ≈ 0.5144 m/s；1 马赫 (Mach, 15℃干燥海平面) ≈ 340.3 m/s = 1225.08 km/h。
