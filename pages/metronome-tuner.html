介绍

节拍器引擎：采用 Web Audio 硬件时钟 Lookahead 预调度算法，彻底规避传统 JavaScript 浏览器主线程由于垃圾回收 (GC) 和 UI 重排造成的节拍不稳与漂移现象。
调音器引擎：采用经过自适应平滑与高斯插值的自相关 (Autocorrelation) 基频检测算法，结合 A4=440Hz 国际标准十二平均律，实现 ±1 Cent 高灵敏度音分误差校准。
