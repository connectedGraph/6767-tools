📚 标识符技术对比与选型指南

标识符规范 长度与字符集 时间有序性 数据库索引友好度 典型应用场景
UUID v4 36字符 (十六进制 + 连字符) ❌ 完全随机 ⚠️ 中等 (随机插入易导致 B-Tree 页分裂) 跨服务防碰撞 ID、短期 Session ID、追踪 Trace ID
UUID v7 (RFC 9562) 36字符 (前 48 位 Unix 毫秒时间戳) ✅ 时间单调递增 ⭐ 极佳 (按时间聚簇索引，写入性能高) MySQL / PostgreSQL / SQLite 数据库主键
ULID 26字符 (Crockford's Base32 编码) ✅ 时间单调递增 ⭐ 极佳 (体积小、URL 友好、支持按时间范围查询) 分布式日志 ID、订单号、消息队列唯一消息 ID
NanoID 默认 21字符 (URL-Safe A-Za-z0-9_-) ❌ 密码学随机 ✨ 良好 (比 UUID 节省 36% 存储空间) 前端组件 Key、短链接 Key、对外暴露的无序实体 ID

🔐 密码学安全性说明

本生成器完全采用 Web 标准的 crypto.getRandomValues() CSPRNG（加密安全伪随机数生成器）在浏览器沙箱本地运行，不依赖 Math.random()，杜绝伪随机序列可预测性，保障唯一性与抗碰撞安全性。所有生成数据完全离线，绝不产生任何网络上传请求。
