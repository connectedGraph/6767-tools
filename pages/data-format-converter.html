💡 配置文件格式互转规范与引擎特性：
📦 JSON (JavaScript Object Notation)
业界通用的标准数据交换格式。严格遵循 RFC 8259 规范，支持标准字符串、数值、布尔值、对象与数组，并具备错误字符位置精准反推行号能力。
📜 YAML 1.2 (Powered by js-yaml 4.1.0)
原生集成官方 js-yaml 引擎，严格遵循 YAML 1.2 规范。支持文档锚点 (&anchor)、别名引用 (*alias)、字典合并 (<<: *merge) 以及多文档 (---) 无损解析与展开。
⚙️ TOML v1.0 (Tom's Obvious Minimal Language)
专为配置文件设计的强类型格式，广泛用于 Cargo、pyproject、Hugo 等。支持多行字符串、表 ([section])、数组表 ([[items]]) 及行内表 ({ a = 1 })。
🏷️ XML (Extensible Markup Language)
结构化标记语言，用于 Maven POM、Spring 及各类企业级数据报文。支持节点属性 (@attr) 映射、子元素集合识别、声明头生成与自定义根节点包装。
